# one_verse -- the public face of the world

This repository contains **only** the pages of the One Verse. It is generated by
`scripts/one_verse_publish.py` from `game/one_verse/` in the vessel, and it deliberately carries nothing
else: no backend, no DNA, no keys, no lab code. Every page here is byte-identical to its source, asserted
at build time.

It is a STATIC world. Opening a page is enough; the puzzles are in the page.

Do not edit these files by hand -- the next build overwrites them.
